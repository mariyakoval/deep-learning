# deep-learning

1. Question: Training a deep learning model to use historical price and macro data with 
financial news sentiment predict the S&P 500's performance and near-term volatility better 
than a model using price data alone.

2. Data: 
- Price, volume, and return data for the S&P 500 (source: yfinance, SPY ticker), 2005–2024
- Macroeconomic indicators from FRED: CPI (inflation), 10Y-2Y Treasury yield spread, 
  federal funds rate.
- Historical financial news text from the Hugging Face "financial-news-multisource" 
  dataset (fnspid_news subset), filtered to S&P-500-relevant tickers.
- Sentiment embeddings generated by passing news text through a frozen, pre-trained 
  FinBERT model.
- Regime labels are not directly available and will be generated by us using a 
  Gaussian Hidden Markov Model fit on realized volatility and returns.

3. Motivation: Market direction (will price go up or down tomorrow) is close to random 
and hard to predict, but volatility and regime are more tractable and directly 
useful in risk management, position sizing, and hedging decisions, because they depend 
on how much prices are likely to swing, not which way. News sentiment often moves before price 
data fully reflects new information, so combining the two modalities may allow 
earlier detection of regime shifts than price data alone.

4. Baseline: A model using only price/macro features (without news sentiment) with the same 
Transformer encoder and classification heads, trained and evaluated on 
identical data splits. This isolates the contribution of the news sentiment branch

5. Plan:
- Weeks 1-2: Build the merged price/macro dataset, generate HMM-based regime 
  labels, build the FinBERT sentiment pipeline, and package everything into a 
  PyTorch dataset.
- Weeks 3-4: Build and train a Transformer encoder + cross-attention architecture 
  with a single classification head (regime prediction).
- Weeks 5-6: Add a volatility regression head, tune the combined loss, and run 
  full out-of-sample evaluation against the price-only baseline.
- Weeks 7-8: Compare model vs. baseline around known historical events (COVID 
  crash, 2022 rate-hike bear market, SVB collapse).

6: Risk: 
- Regime labels are self-generated, so results are only as reliable as our labeling method; 
  we mitigate this by validating labels against known historical crisis periods before training.
- News sentiment coverage may be sparse or noisy on some trading days.
- A Transformer architecture needs a lot of data; we mitigate this by keeping the model small 
  (2-4 layers) and comparing against the simpler baseline
